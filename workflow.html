Personal Trainer
How It Works

A progressive training programme with an AI coach — built as a single file, zero accounts required.

01

Four Screens

The app has four tabs, each serving a distinct purpose in the training workflow.

🏋️

Today

Today's session — exercises, sets, reps, weight and RPE fields ready to log.

📈

Progress

Charts and PRs across all exercises. See your strength curve over the programme.

📋

Programme

Full plan — every session, every exercise, every target weight. Tap any week for an overview.

🤖

AI Coach

Claude-powered chat that reads your actual training data to give personalised advice.

02

Training Blocks

The programme is divided into four periodisation blocks. Each has a distinct colour and training focus.

Base

Foundation

Moderate loads, technique focus, establish consistency.

Build

Overload

Weights increase weekly, RPE climbs toward 8–9.

Peak

Intensity

Heaviest loads of the cycle, near-maximal effort.

Deload

Recovery

Light loads, full range of motion. Let the work sink in.

Each week has three sessions — Push, Pull, Legs — plus run days.

03

Logging a Session

Tap through each exercise on the Today screen. When you're done, the session saves automatically.

1

Open Today tab

The app shows the correct session for today — Push, Pull, or Legs — based on the current week.

2

Log each set

Enter weight, reps and RPE for each exercise. Tap the checkmark when a set is complete.

3

PRs detected automatically

If you lift more than your previous best, the app flags it as a PR in real time.

4

Finish session

Tap Complete. The session is saved and the week advances.

5

Log your run

On run days, enter distance, time, heart rate and run type. Saved the same way.

04

Data Storage

Everything lives in your browser — no server, no account, no sync. Export a JSON backup any time from Settings.

Sessions
All logged gym sessions with exercises, sets, reps, weights and RPE
Runs
Run logs — distance, time, heart rate, type, date
Bodyweight
Daily weight entries
PRs
Personal records — max weight lifted per exercise
Programme
Your custom AI-built routine, including all weeks and exercises

Backup tip

Use the Export button in Settings to download a JSON file. If you ever clear your browser data or switch devices, import the file to restore everything.

05

Progress Tab

The Progress screen turns your logged data into charts — no setup required.

📊

Strength Charts

Weight over time for each exercise. See your progression week by week.

🏆

PR Board

Your all-time best weight for every exercise, updated automatically when you hit a new high.

🏃

Run Stats

Pace, time and heart rate trends across all logged runs.

⚖️

Bodyweight

Track your weight over the programme with a simple line chart.

06

AI Coach

The AI Coach connects to Claude and automatically injects your real training data into every conversation — so the advice is always about your actual sessions, not generic tips.

1

Build your programme

First time? The coach runs an intake — asking about your goals, experience and schedule — then generates a fully personalised programme for you.

2

Ask anything

Use the quick-start cards or type freely — "Why am I stalling on squat?", "Is my RPE too high this week?", "What should I focus on today?"

3

Context is built automatically

Your session history, PRs, current week, bodyweight and run data are all bundled into every message behind the scenes.

4

Streamed responses

Replies appear word by word in real time. The conversation is saved so you can pick up where you left off.

API key required

The AI Coach needs an Anthropic API key to work. Add yours in Settings — it's stored only on your device and never sent anywhere except directly to Claude.

07

Add to Home Screen

The app works as a PWA — add it to your home screen for a full-screen, app-like experience.

📱

iPhone

Open in Safari → Share → Add to Home Screen. Opens full-screen like a native app.

🤖

Android

Open in Chrome → menu → Add to Home Screen.

🔒

Offline Ready

Once loaded, the app works without internet. All data stays on your device.
