How navigation works
Tapping a tab icon calls render(), which reads the global currentTab variable and calls the matching renderer (renderLog(), renderProgress(), renderCoach(), renderSettings()). No routing library — one function, one switch.

Default vs custom programme
The built-in WEEK_DATA array is always present. If the AI Coach generates a custom plan and the user confirms it, it's saved to kt_routine in localStorage. After that getWkData() returns data from the custom plan instead of the default array — until the user resets it in Settings.

4 — What's stored in the browser
🏋️
kt_sessions
Every logged gym session: date, exercises, sets, reps, weights, RPEs
🏃
kt_runs
Logged run sessions: date, type, distance, time, calculated pace
⚖️
kt_weights
Body weight entries over time. Shown as a trend line in Progress tab.
🏆
kt_prs
Personal record per exercise name. Updated automatically when a new max is logged.
🤖
kt_routine
AI-generated custom programme JSON. Overrides the built-in WEEK_DATA when present.
🔑
kt_apikey
Anthropic API key. Used by the Coach tab to call Claude directly from the browser.
🎨
kt_theme
Active color theme name (lime, cyan, violet, rose, amber). Applied on startup.
📅
kt_week
Current week number (1–12). Determines which WEEK_DATA row loads.
💾
All data = localStorage
No server. No account. Everything lives in the browser. Export JSON from Settings as backup.
5 — What the Progress tab shows
📊
Volume chart
Weekly training volume (sets × reps × weight) visualised as bars per muscle group.
🏆
Personal records
Best weight ever lifted per exercise. Updated automatically, displayed as lift-bar indicators.
⚖️
Bodyweight trend
Daily weight entries plotted over time. Log new entries directly from this screen.
🏃
Run pace chart
Pace per km over time. Easy, tempo, and interval runs shown in distinct colours.
📋
Session history
Scrollable list of past sessions with mini cards showing volume and top lifts.
💪
Lifts this block
Shows lift-bar progress for each exercise in the current 3-week training block.

7 — How it's delivered
📱
Installable PWA
Can be added to home screen on iOS and Android. Opens full-screen with no browser chrome.
✈️
Works offline
Service worker (sw.js) caches the app shell. Log workouts without a network — only AI Coach needs internet.
🚀
Auto-deploy on Vercel
Any push to the main git branch triggers a new deploy. No build step — just static HTML.
🎨
5 color themes
Lime, Cyan, Violet, Rose, Amber. Change in Settings — saved to localStorage instantly.
📤
Data export / import
Settings tab lets you download a full JSON backup of all localStorage data and re-import it on any device.
🔒
No account needed
Zero sign-up, zero server. Your API key and training data never leave your device — except for the direct API call to Anthropic.
