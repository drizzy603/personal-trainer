Personal Trainer
How It Works

A progressive training programme with an AI coach — built as a single file, zero accounts required.

01

Four Screens

The app has four tabs, each serving a distinct purpose in the training workflow.

🏋️

Log

Today's session — exercises, sets, reps, weight and RPE fields ready to log. Run days included.

📈

Progress

Charts and PRs across all exercises. See your strength curve, run pace, and bodyweight over 12 weeks.

💬

Coach

Claude-powered chat that reads your actual training data — and can update the app directly from conversation.

⚙️

Settings

API key, week controls, export/import backup, and this walkthrough.

02

Training Blocks

The programme is divided into four periodisation blocks. Each has a distinct colour and training focus.

Base

Foundation

Moderate loads, technique focus, establish consistency.

Build

Overload

Weights increase weekly, RPE climbs toward 8–9.

Peak

Intensity

Heaviest loads of the cycle, near-maximal effort.

Deload

Recovery

Light loads, full range of motion. Let the work sink in.

Each week has three gym sessions — Push (Mon), Pull (Thu), Legs (Fri) — plus two runs (Tue easy / Sat long). Wednesday and Sunday are rest days.

03

Logging a Session

Tap through each exercise on the Today screen. When you're done, the session saves automatically.

1

Open Today tab

The app shows the correct session for today — Push, Pull, or Legs — based on the current week.

2

Log each set

Enter weight, reps and RPE for each exercise. Tap the checkmark when a set is complete.

3

PRs detected automatically

If you lift more than your previous best, the app flags it as a PR in real time.

4

Finish session

Tap Complete. The session is saved and the week advances.

5

Log your run

On run days, enter distance, time, heart rate and run type. Saved the same way.

04

Data Storage

Everything lives in your browser — no server, no account, no sync. Export a JSON backup any time from Settings.

Sessions
All logged gym sessions with exercises, sets, reps, weights and RPE
Runs
Run logs — distance, time, heart rate, type, date
kt_weights
Working weights map — exercise name → current target weight in lb
kt_prs
Personal records — exercise name → max weight ever lifted
kt_week
Current week number (1–12)
kt_bw
Array of bodyweight entries — {date, weight} — most recent first
kt_run_goal
Target pace per km as "mm:ss" (e.g. "6:00")
kt_5k_goal
Target 5k finish time in seconds
kt_bw_goal
Target bodyweight in lb
kt_coach_msgs
Coach chat history — persists across sessions, last 60 messages kept

Backup tip

Use the Export button in Settings to download a JSON file. If you ever clear your browser data or switch devices, import the file to restore everything.

06

AI Coach

The Coach tab connects to Claude via your Anthropic API key. Every message automatically includes your real training data — so advice is always about your actual sessions, not generic tips. Conversation history persists across sessions.

1

Coach home menu

Tapping the Coach tab shows a landing menu — open the chat, view conversation count, or disconnect. You're never dropped straight into the last message.

2

App builds context automatically

Your session history, PRs, current week, run data, exercise weights, and goals are injected into the system prompt on every message.

3

Claude streams a response

The reply is specific to your numbers, streamed word-by-word in real time. Responses time out after 30 seconds if the connection drops.

4

Coach can update the app directly

Ask the coach to change something and it will update the app without you leaving the chat. Supported actions:

  • Exercise weights — "bump my bench to 172.5 lb"
  • Current week — "move me to week 4"
  • Log bodyweight — "I'm 181 lb today"
  • Run pace goal — "set my pace goal to 6:00/km"
  • 5k time goal — "update my 5k target to 30:00"
  • Bodyweight goal — "my target weight is 175 lb"

How coach actions work

When you ask for a change, Claude embeds a hidden action block in its reply. The app parses it, updates localStorage, and re-renders the relevant screen — all before you finish reading the response. The action block is stripped from the chat bubble so you only see clean text.

08

Render Loop

The app uses a minimal reactive pattern — no framework required.

1

State lives in localStorage

Sessions, runs, PRs and week number are read from localStorage on every render.

2

User action triggers save()

Any input — logging a set, completing a session — writes to localStorage immediately.

3

render() redraws the screen

The active tab re-renders from scratch using the latest state. Fast, simple, no virtual DOM.

4

Streamed responses

Replies appear word by word in real time. The conversation is saved so you can pick up where you left off.

API key required

The AI Coach needs an Anthropic API key to work. Add yours in Settings — it's stored only on your device and never sent anywhere except directly to Claude.
